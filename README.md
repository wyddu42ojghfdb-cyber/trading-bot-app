# 📈 منصة إدارة وتداول الأرصدة الذكية (Algo-Trading Bot System)

تطبيق متكامل مخصص لإدارة أموال وتداولات المشتركين يدويًا من قِبل المشرف مع نظام إحالة ومكافآت متطور.

## 💰 القواعد المالية والنسب الرسمية للنظام:
* **الحد الأدنى للإيداع:** 100\$ لكل مستخدم (لتفعيل الحساب النشط).
* **نسبة أرباح الصفقة اليومية:** 15% تضاف لرأس المال النشط بضغطة زر من المشرف.
* **مكافأة دعوة الأصدقاء:** يحصل الداعي على 20% من صافي أرباح الصديق عند كل صفقة.
* **جائزة النمو الكبرى (البونص):** يحصل المستخدم على 10,000 مكافأة تلقائية فور وصول عدد أصدقائه النشطين (الذين أودعوا 100+) إلى 40 صديقًا.

## 🛠️ المكونات البرمجية للمشروع:
1. **`main.py`**: يحتوي على الكود البرمجي الخلفي (Backend Logic) وقاعدة بيانات SQLite لإدارة الحسابات.
2. **`requirements.txt`**: يحتوي على المكتبات البرمجية المطلوبة لتشغيل خادم التطبيق (FastAPI).

## 🚀 طريقة تشغيل المشروع تجريبيًا (للمطورين):
1. قم بتثبيت المكتبات: `pip install -r requirements.txt`
2. قم بتشغيل السيرفر: `uvicorn main:app --reload`
3. افتح لوحة التحكم البرمجية عبر الرابط: `http://127.0.0`
